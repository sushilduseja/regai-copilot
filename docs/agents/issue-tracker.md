# Issue Tracker

## Platform

GitHub Issues.

## Repository

`https://github.com/sushilduseja/regai-copilot`

## CLI

Use the `gh` CLI for all issue operations:

- `gh issue create` — create new issues
- `gh issue list` — list issues
- `gh issue view <number>` — view an issue
- `gh issue edit <number> --add-label <label>` — apply labels
- `gh issue close <number>` — close an issue

## Workflow

Issues are created, triaged, and managed through GitHub's native issue system. All engineering skills (`to-issues`, `triage`, `to-prd`, `qa`) read from and write to this tracker.
