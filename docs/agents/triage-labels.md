# Triage Labels

The five canonical triage labels used by the `triage` skill:

| Label | Role |
|---|---|
| `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | Fully specified; an AI agent can pick it up with no human context |
| `ready-for-human` | Needs a human to implement |
| `wontfix` | Will not be actioned |

No custom overrides — each label string equals its canonical name.
